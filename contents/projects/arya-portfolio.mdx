## Introduction

Personal portfolio and developer dashboard built from scratch by **Atsiila Arya Nabiih**, deployed at [atsiilaarya.me](https://atsiilaarya.me).

I designed and engineered this platform to:

- Present software engineering, web, mobile, and UI/UX case studies with full bilingual copy (`ID` / `EN`)
- Surface live open-source GitHub contributions and real-time portfolio traffic analytics
- Experiment with tactile UI craft, accessible interaction patterns, and Core Web Vitals optimization

The full source code is open under the MIT License on [GitHub](https://github.com/arzss-code/arya-portfolio).

---

## Tech Stack

- **Framework:** Next.js 16 (App Router & Turbopack)
- **Language:** TypeScript 5.7
- **Styling & Design System:** Tailwind CSS + Custom 5-Layer Tactile / Rim-Lit CSS Tokens
- **Motion:** Framer Motion, GSAP, Lenis
- **Database & CMS:** Supabase PostgreSQL (`@supabase/ssr`) + MDX Case Studies
- **Data Fetching & State:** Server-Side Pre-fetching + SWR + Zustand
- **Internationalization:** `next-intl` (Indonesian & English)
- **Analytics:** PostHog Insights + GitHub GraphQL API + Vercel Analytics

---

## Key Capabilities

### Tactile Rim-Lit Interface & Accessibility

Built around custom recessed tracks and specular rim-lit action surfaces inspired by modern hardware keycaps and design systems. Includes semantic `<search>` landmarks, keyboard Skip-to-Content navigation, focus-restoring modals, programmatic form labels, and `prefers-reduced-motion` support.

### Hybrid SSR + SWR Portfolio Collections

Project and achievement records live in **Supabase PostgreSQL**, pre-rendered on the server as `initialData` so search engine crawlers index every card and internal link immediately, while SWR keeps client navigation fast.

### Developer & Traffic Dashboard

Interactive `/dashboard` route combining:

- **GitHub Contributions:** Live contribution calendar and repository metrics via the GitHub GraphQL API
- **Traffic Trends:** Visitor, session, country, and page-view analytics from PostHog Insights

### Technical SEO & Core Web Vitals

- Dynamic `/sitemap.xml`, `/robots.txt`, Web App Manifest, and `next/og` Open Graph image generation (`1200x630`)
- Structured JSON-LD (`ProfilePage`, `Person`, `WebSite`, `Service`, `CollectionPage`, `SoftwareSourceCode`, `BreadcrumbList`) and `/llms.txt`
- Measured **`223 ms` desktop LCP** and **`0.00` mobile CLS** on production builds

## Running Locally

```bash
git clone https://github.com/arzss-code/arya-portfolio.git
cd arya-portfolio
npm install
npm run dev
```

Configure `.env.local` using the environment variable guide in [README.md](https://github.com/arzss-code/arya-portfolio#2-configure-environment-variables), then open `http://localhost:3000`.
